## 🛠️ The Tech Stack

- **Framework**: [React 19](https://react.dev/) with [TypeScript](https://www.typescriptlang.org/)
- **State Management**: [Redux Toolkit](https://redux-toolkit.js.org/) (Persistent Theme & Global State)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) (Atomic CSS with CSS Variables)
- **Animations**: [Framer Motion](https://www.framer.com/motion/) (Smooth transitions & micro-interactions)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)

---

## ✨ Key Features

- **🌓 Dynamic Theme System**: Full Dark/Light mode support powered by Redux and CSS Variables, with system preference detection and `localStorage` persistence.
- **🏗️ Architectural Excellence**: Implementation of Clean Architecture principles and MVC Repository patterns in project simulations.
- **📱 Fluid Responsiveness**: Mobile-first design ensuring a premium experience on everything from ultra-wide monitors to smartphones.
- **📊 Data Visualization**: Integrated **Recharts** for the Finance Dashboard project simulation.
- **⚡ Optimized Performance**: Fast TTI (Time to Interactive) and high Lighthouse scores through Vite's lightning-fast build system.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/ansaralikunju311311/Portfolio.git
   ```

2. **Navigate to the directory**
   ```bash
   cd Portfolio
   ```

3. **Install dependencies**
   ```bash
   npm install
   ```

4. **Start the development server**
   ```bash
   npm run dev
   ```
